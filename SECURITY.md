# Security

## Reporting

Please use GitHub private vulnerability reporting if it is available for this repository.

If private reporting is unavailable, open a public issue that describes the class of problem without including exploit details, credentials, private URLs, or sensitive logs.

## Sensitive Data Policy

Do not include:

- secrets, tokens, private keys, or auth output;
- `.env` files or copied environment values;
- local absolute paths from a real workstation;
- private repository names or deployment identifiers;
- raw social-media exports or private messages;
- logs that contain request headers, cookies, account identifiers, or service URLs.

Use placeholders such as `OWNER/REPO`, `example.invalid`, and `https://example.com`.
